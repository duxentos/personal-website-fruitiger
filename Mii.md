# Mii Character — Personal Portfolio Avatar

Create a custom 3D Mii-inspired character representing me, designed to integrate seamlessly into my Frutiger Aero personal portfolio.

## Character Design

The character should have the charming, minimalist visual style of a classic Nintendo Wii Mii.

### Appearance
- Young male university engineering student.
- Short, dark brown or black, slightly wavy hair.
- Natural medium skin tone.
- Dark brown eyes.
- Expressive eyebrows.
- Friendly, relaxed expression.
- Rounded, simplified facial features.
- Small, minimalist nose.
- Subtle smile.
- Clean-shaven.
- Cartoonish, approachable proportions.

Do not attempt photorealism. Prioritise the recognisable simplicity and personality of classic Mii characters.

These are initial design defaults, not claims about my exact appearance. Make all facial features customisable.

### Clothing
- Casual crewneck or hoodie.
- Optional University of Waterloo-inspired gold and black colour scheme.
- Simple, rounded cartoon body.
- Clothing should complement the website's vibrant Frutiger Aero aesthetic.

## Visual Style

- Nintendo Wii-era 3D character aesthetic.
- Smooth, matte skin shading.
- Rounded geometry.
- Minimal facial detail.
- Soft ambient lighting.
- Subtle glossy highlights.
- Clean silhouettes.
- Expressive but understated facial animations.
- Avoid realistic textures or excessive detail.

The character should look like it belongs in a nostalgic 2006–2012 interactive desktop environment.

## Website Integration

Position the Mii as a small interactive personal assistant or desktop companion.

Implement:

1. **Idle:** Gentle blinking and subtle breathing.
2. **Hover:** Looks toward the cursor or slightly tilts its head.
3. **Click:** Waves or performs a brief greeting animation.
4. **Navigation:** Reacts subtly when a project window opens.
5. **Projects:** Can display a small speech bubble with a short description of the selected project.

Make all interactions optional and nonintrusive.

## Technical Constraints

- Use React and TypeScript.
- Prefer Three.js with React Three Fiber for a true 3D avatar.
- Construct the character using simple geometry and lightweight materials.
- Avoid downloading or copying Nintendo-owned character models.
- Create an original character inspired by the simplicity of Mii avatars.
- Keep geometry and animations lightweight.
- Support mobile devices.
- Respect reduced-motion accessibility preferences.
- Avoid unnecessary libraries.
- Ensure the avatar does not block navigation or important content.

## Customisation

Keep facial features, hair, clothing, and colours configurable through a central character configuration object.

Allow the avatar's design to be adjusted without rewriting the rendering logic.

## Important Constraints

- Do not use emojis as facial features.
- Do not use a generic robot avatar.
- Do not use an AI-generated stock profile picture.
- Do not make the character excessively realistic.
- Do not make the avatar constantly move.
- Do not sacrifice website performance for visual complexity.
- Do not add unnecessary dialogue or distracting speech bubbles.

## Final Objective

Create an original, recognisable, charming Mii-style character that serves as my digital identity throughout the portfolio.

It should look like a character from the Nintendo Wii era, reimagined as a personal desktop companion for a colourful Frutiger Aero website.
