# Codex Prompt — Mobile Responsiveness & Adaptive Frutiger Aero UI

## Objective

Make my existing Frutiger Aero personal portfolio fully responsive, touch-friendly, performant, and visually polished across mobile phones, tablets, laptops, and desktop monitors.

**The mobile version must feel like a purpose-built nostalgic mobile operating system, not a desktop website squeezed onto a smaller screen.**

Preserve the existing Frutiger Aero aesthetic, project explorer, animations, Mii character, colourful gradients, and glossy desktop UI.

Do not rebuild the website from scratch.

## 1. Mobile-First Responsive Design

Support the following viewport ranges:

- Small phones: 320–374px
- Standard phones: 375–430px
- Large phones: 431–599px
- Tablets: 600–1023px
- Laptops: 1024–1439px
- Large desktops: 1440px+

Use responsive CSS and content-driven breakpoints rather than hardcoding layouts for individual devices.

Requirements:

- No horizontal page overflow.
- No clipped text or navigation.
- No overlapping buttons.
- No inaccessible windows.
- No oversized margins on mobile.
- No fixed-width desktop components extending beyond the viewport.
- Support portrait and landscape orientations.
- Account for display cutouts, safe areas, and mobile browser controls.

## 2. Adaptive Desktop Experience

### Desktop

Preserve the full Windows Vista-inspired desktop interface:

- Floating windows.
- Desktop icons.
- Glossy navigation dock.
- Draggable project windows.
- Interactive Mii companion.
- Animated Frutiger Aero background.

### Mobile

Transform the desktop into a compact, touch-first interface inspired by early iPhone OS, Windows Mobile, and the Nintendo Wii.

Use:

- A compact glossy top status bar.
- A responsive application-style home screen.
- A grid of tappable project icons.
- Full-screen project windows.
- A mobile-friendly navigation dock.
- Smooth app-opening transitions.
- Rounded translucent panels.
- A simplified Frutiger Aero background.

Do not attempt to preserve desktop window dragging on touchscreens.

Instead, opening a project should display a dedicated full-screen view or mobile sheet.

Include a clearly visible back button.

## 3. Mobile Navigation

Replace the desktop floating navigation dock with a compact bottom navigation system on smaller screens.

Navigation should support:

- Home
- Projects
- About
- Experience
- Contact
