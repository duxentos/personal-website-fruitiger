ClinTempo — AI-Powered Clinical Documentation Assistant

An AI-powered healthcare assistant that streamlines clinical documentation through real-time transcription, automated medical note generation, and customizable templates. Designed to reduce administrative workload and allow healthcare professionals to focus more on patient care.

Tech Stack: React, TypeScript, Node.js, Express.js, Corti AI API, Chrome Extension APIs.

Architecture: Full-stack, client-server architecture with a React frontend, Express.js REST API backend, and Corti AI integration for clinical transcription and structured note generation. Features editable AI-generated notes, reusable templates, and browser-based local storage, with cloud synchronization planned.

   GOOSE — AI-Powered macOS Productivity Companion

An interactive macOS Dynamic Island-inspired productivity assistant designed for students, combining academic deadlines, calendars, notifications, AI-powered task management, and an animated virtual goose into a seamless desktop experience.

Tech Stack: React, TypeScript, Tauri, Rust, PixiJS, SQLite, macOS Native APIs.

Architecture: Event-driven desktop application built with a React frontend and a Rust-powered Tauri backend. Uses SQLite for local data persistence, PixiJS for interactive animations, and native macOS APIs for system-level window management. Designed to integrate external services including Google Calendar, Waterloo LEARN, Discord, and Spotify through modular API integrations.
